# Repositories

`apps/`, `games/`, `drivers/`, `extras/` (themes, fonts, sounds) and `ui/` (official shells). Each is a repository in the format of `Repositories/SPEC.md` of the firmware repository: `repo.json`, `repo.json.sig`, `index.json`, `index.json.sig`, with the packages beside them. `apps/` and `ui/` exist and are signed; `games/`, `drivers/` and `extras/` do not exist yet. A folder starts with its `repo.toml`.
